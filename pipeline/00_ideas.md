**IDEA A — El Panóptico**
**Conexión:** Bentham (panóptico, 1787) + redes sociales hoy
**Mecanismo:** No necesitas que alguien te vigile — basta con que *puedas* ser visto para que te comportes como si siempre lo fueras. El panóptico es la arquitectura del autocontrol involuntario.
**Entrada posible:** "La cámara no necesita estar encendida."
**Incomodidad final:** "El vigilante más eficaz ya vive dentro de ti."
**Formato:** Conexión Improbable
**Solapamiento:** Ninguno con los 12 actuales ✓
**Plataforma:** Alto potencial — el tema de vigilancia en redes tiene tracción orgánica constante
**Decisión:** ⬜ SÍ / ⬜ NO / ⬜ DESPUÉS

**IDEA B — Sapir-Whorf**
**Conexión:** Hipótesis Sapir-Whorf + el idioma ruso tiene dos palabras para azul (goluboy / siniy) y sus hablantes distinguen el color más rápido
**Mecanismo:** El idioma que hablas construye lo que puedes percibir. No es que no tengas palabras — es que no tienes el concepto.
**Entrada posible:** Una emoción que sientes pero no puedes nombrar.
**Incomodidad final:** "Hay cosas que no puedes sentir completamente porque tu idioma nunca te enseñó a verlas."
**Formato:** Historia / Conexión Improbable
**Solapamiento:** Ninguno ✓
**Plataforma:** Muy compartible — la demo del azul ruso es visualmente impactante
**Decisión:** ⬜ SÍ / ⬜ NO / ⬜ DESPUÉS

**IDEA C — Frans de Waal / Capuchinos**
**Conexión:** Experimento de capuchinos (de Waal, 2003) — rechazan pepino cuando el otro mono recibe uva
**Mecanismo:** La inequidad no es un invento moderno. No elegiste compararte. Ya venías así.
**Entrada posible:** El mono tira el pepino con furia. Lleva millones de años haciendo eso.
**Incomodidad final:** El instinto de comparación no es debilidad — pero tampoco tiene por qué gobernar.
**Verificar:** solapamiento con Script 03 (aversión a la pérdida) — son mecanismos distintos pero revisar destino emocional final
**Formato:** Historia
**Plataforma:** El video del experimento original es viral — la referencia es reconocible
**Decisión:** ⬜ SÍ / ⬜ NO / ⬜ DESPUÉS

**IDEA E — Regla del 37% (problema del secretario)**
**Conexión:** Matemática de decisiones óptimas + el momento en que uno deja de buscar para comprometerse
**Mecanismo:** Matemáticamente, el momento óptimo para elegir es después de haber rechazado el 37% de las opciones disponibles. Antes eso, no tienes criterio. Después, perdiste tus mejores opciones.
**Entrada posible:** "¿Cuándo sabes que ya encontraste lo suficientemente bueno?"
**Incomodidad final:** Hay una tensión irresolvible entre criterio y oportunidad — y la matemática no la resuelve, solo la nombra.
**Verificar solapamiento:** Script 05 (El Costo de Elegir) toca la parálisis por opciones — este toca *cuándo* comprometerse. Diferentes, pero revisar antes de escribir.
**Formato:** Conexión Improbable
**Decisión:** ⬜ SÍ / ⬜ NO / ⬜ DESPUÉS
